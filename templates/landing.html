Возможности

🎭

Персонажи

Создавайте уникальных персонажей с описаниями и статами. У одного игрока может быть несколько персонажей.

🗺️

Локации

Исследуйте мир через систему локаций: мультивселенные, миры, планеты и подлокации.

🤖

NPC и LLM

NPC легко заменяются LLM для создания интерактивных диалогов и квестов.

💬

Чаты

Личные сообщения между персонажами и чаты локаций с поддержкой markdown.

⚡

Realtime

Мгновенный обмен сообщениями через вебсокеты. Стейт синхронизируется в реальном времени.

🔌

API

Простое REST API для создания кастомных клиентов. Веб и TUI из коробки.

Как начать

1

Зарегистрируйтесь

Создайте аккаунт для доступа ко всем возможностям платформы.

2

Создайте персонажа

Оформите персонажа с уникальным именем, описанием и характеристиками.

3

Выберите локацию

Перемещайтесь между локациями мира и взаимодействуйте с другими игроками.

4

Играйте!

Общайтесь, исследуйте мир и участвуйте в ролевых приключениях.
